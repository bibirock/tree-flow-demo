# 展示資料與來源檢查

本展示使用重新撰寫的 React 程式與可重現的合成資料，不放入原工作專案的資料集、業務名稱、來源識別、工作單編號、內部網址或實際資料規模。

## 已處理

- 資料規模改為一般合成測試級距，不使用原系統的特定數字。
- 依使用者要求搬入的提交規範已改寫為通用版本，移除來源專案的 adapter 依賴、工作單範例、來源識別與歷史效能數字。
- MCP 設定只保留公開工具啟動資訊，沒有搬入其他連線、認證或原專案設定。
- 比對來源版本與展示工作目錄的檔案內容雜湊，未發現完全相同的程式或文件檔。此檢查驗證整檔一致性，不宣稱能證明所有片段都毫無相似；常見演算法與公開工具設定可能自然相似。
- 本機尚未推送的 Git 歷史也清理來源數字與舊版 skill 內容，並依開發基底、圖形功能、Canvas 改善、回退測試與交付文件的依賴順序整理提交。重整會更新提交雜湊，最終交付檔案維持一致。
- 不交付過程中的測試 traces、舊建置產物或舊截圖；保留目前測試頁的驗收截圖。

原工作專案未修改。本展示未設定 Git 遠端，也未推送或發布。
